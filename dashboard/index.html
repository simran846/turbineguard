TurbineGuard Architecture & Overview

TurbineGuard is a Software-in-the-Loop (SIL) validation and automated test platform designed to verify supervisory control algorithms for utility-scale 2.5 MW wind turbines.

System Overview

The platform integrates an aerodynamic inflow model, two-mass rotational drivetrain physics, a multi-region supervisory controller (Region 1 cut-in, Region 2 MPPT torque control, Region 3 collective pitch PID), an asynchronous fault injection engine, and an automated requirements verifier.

Simulated Data Notice: All operating data, aerodynamic coefficients, and telemetry streams are generated mathematically through closed-loop differential equations for education and controller verification purposes.

Key Verification Criteria

  • REQ-001: Maximum continuous rotor speed envelope (≤ 1,725 RPM).
  • REQ-002: Critical overspeed trip triggering aerodynamic feathering within ≤ 250 ms.
  • REQ-003: Maximum generator thermal envelope (≤ 98.0°C).
  • REQ-004: Cut-in wind speed threshold validation (≥ 3.0 m/s).
  • REQ-005: Cut-out high wind survival trip (≥ 25.0 m/s).
  • REQ-006: Maximum pitch rate limitation (≤ 8.0 deg/s).

REST API Endpoints

The backend exposes RESTful endpoints for headless CI/CD execution:

POST /simulation/start • Execute closed-loop simulation
POST /faults/inject • Schedule and inject abnormal conditions
POST /validation/run • Run formal REQ-001..012 validation
GET /telemetry/data • Fetch time-series signal arrays
GET /reports/download/{f}• Download PDF, HTML, CSV, or JSON
